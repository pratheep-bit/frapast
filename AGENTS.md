# Agent Directives & Privacy Guidelines

## Confidentiality & Public Anonymity Rules
1. **Zero Company / Client Exposure**: Never include, reference, or commit any private company names, client organization identities, employee names, internal URLs, or proprietary infrastructure details in any public repository, documentation, commit messages, or exported artifacts.
2. **Open Source Identifiers Only**: All benchmarks, examples, and documentation must exclusively reference public, open-source repositories and standard framework components (e.g., `frappe/frappe`, `frappe/erpnext`, `frappe/hrms`).
3. **No Competitor Brand Promotion**: Do not mention proprietary competitor product names or commercial vendor entities in documentation. Use general category descriptions (e.g., "Generic SAST tools", "Cloud-hosted scanners").
4. **Professional Typography & Tone**: All technical documentation, code comments, and CLI outputs must maintain a clean, formal, enterprise-ready tone without emoji characters.
